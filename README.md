# Product Inventory System
A **product inventory management program** written in C. This program enables the user to add, search, update, remove, and display products in the inventory. The inventory data can also be exported as a CSV file for later use.

### Features
- Each product stores the information:
  - Name
  - ID
  - Quantity
  - Price
  - Category
- Add products to the inventory
- Find products in the inventory by name, ID, quantity, price, or category
- Update quantity of an existing product in the inventory
- Display all products in the inventory
- Save all products in the inventory into a CSV file
- Can store up to 100 products in the inventory
- A menu system showing options on what to do in the inventory

### CSV
Selecting save to CSV creates a file named inventory.csv and uses the format:

Name,ID,Quantity,Price,Category

### How to Run Program
- i. Clone this repository
- ii. Open this project folder in a terminal
- iii. Compile this program using a C compiler
- iv. Run the compiled program
